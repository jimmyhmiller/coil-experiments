# Training planner executable

Create the Coil module `experiments.markdown-demo.main`.

Import `experiments.markdown-demo.training` and the appropriate standard Coil
I/O module. Define `main` returning `i64`.

Calculate the six-week total for a plan starting at 15 miles and increasing by
3 miles each week. Print exactly this line followed by a newline:

```text
Six-week total: 135 miles
```

Return `0` when the calculated total is `135`; otherwise return `1`.
